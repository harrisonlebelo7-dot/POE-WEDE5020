Our Learning Locations

CodeBridge aims to make programming lessons accessible to learners in different communities. The organisation will provide learning opportunities at more than one location to make it easier for learners to attend lessons.

Polokwane Learning Centre

Our Polokwane learning centre provides programming lessons in a supportive environment. Learners will have access to lessons designed to help them develop programming knowledge and practical problem-solving skills.

Location: Polokwane, Limpopo

Seshego Learning Centre

The Seshego learning centre provides programming learning opportunities for learners from Seshego and surrounding communities. The centre is intended to provide a convenient environment for beginners who want to develop their programming skills.

Location: Seshego, Limpopo
