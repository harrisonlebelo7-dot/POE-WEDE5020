Project Overview:
        •	Organization Name: CodeBridge Learning Initiative
        •	CodeBridge Learning Initiative is a small non-profit educational organization that
            provides affordable and accessible programming lessons to high-school learners, university students and young people who are interested in developing their computing skills. The organization was established to help reduce the digital skills gap by providing practical programming education to individuals who may not have access to expensive technology courses.
        •	The organization’s mission is to empower young people with practical programming
            skills that can support their education, future careers and entrepreneurial opportunities. Its vision is to become a trusted community-based programming organization that helps create a genetic of digitally skilled, innovative and confident young people.
        •	The primary target audience includes high-school learners, university students and
            unemployed youth and beginners who want to learn programming lessons easily accessible

        Website Goals and Objectives:
            The primary goal of the proposal website is to create a professional online presence for CodeBridge Learning Initiative and make information its programming lessons easily accessible.

        The main objectives of the website are to:
        •	Provide information about the programming lessons offered.
        •	Allow learners to submit enquiries about available lessons.
        •	Encourage qualified programmers to volunteer as tutors.
        •	Attract sponsors interested in supporting programming education.
        •	Increase awareness of CodeBridge within the local community.
        •	Provide visitors with information about lesson locations and contact details.

        The website will also provide information about the programming languages taught, course levels, lesson schedules and available learning locations. This will allow visitors to understand what CodeBridge offers before submitting an enquiry.

        The organization will use Key Performance Indicators (KPIs) to measure the success of the website. These will include the number of website visitors, programming lesson enquiries, completed enquiry forms, volunteer applications and sponsor enquiries. The organization can also monitor the number of visitors to different pages to determine which information attracts the most interest.

Key Features and Functionality:
    Functionality
    The website will contain five main pages: Home, About Us, Lessons, Enquiry and Contact. Each page will have a consistent navigation menu so that visitors can easily move between the different sections of the website.

    Home Page
        The Home page will introduce CodeBridge through a hero section containing the organization’s name, a short description and a clear call-to-action button. The page will also contain a brief introduction to the organization and an overview of the programming lessons available. Visitors will be encouraged to view the Lessons page or submit an enquiry.

    About Us Page
        The About Us page will provide information about the organization’s history, mission, vision and objectives. It will also introduce the tutors and explain how CodeBridge aims to support learners through programming education.

    Lessons Page
        The Lessons page will provide detailed information about the programming courses offered. It will include beginner programming, Python, Java and JavaScript. Each course will have a short description explaining what learners can expect to learn. The page will also provide information about course levels, lesson duration and available locations.

    Enquiry Page
        The Enquiry page will contain a form where prospective learners can provide their name, email address, programming interest and enquiry. The form will include required fields to ensure important information is provided. JavaScript will later be used to perform client-side validation and provide feedback when information is missing or entered incorrectly.

    Contact Page
        The Contact page will provide the organization’s email address, telephone number, operating hours and more than one lesson location. An embedded Google Map will be included to help visitors find the lesson venues. The page will also provide a way for visitors to contact the organization directly.

    Other functionality will include working navigation links between all pages, call-to-action buttons and interactive elements that will be developed further during the CSS and JavaScript stages of the

Part 2 – Designing the Visuals: CSS Styling and Responsive Design

    Part 2 Overview:

        For Part 2, I focused on improving the visual design and layout of the CodeBridge Learning Initiative website.

        I created an external CSS stylesheet called `style.css` and linked it to all five HTML pages. The CSS was used to make the website more consistent, readable and easier to use.

        I also corrected some of the issues from Part 1, including spelling mistakes, image paths and HTML structure.

        The main CSS concepts used in Part 2 were:
            * CSS reset
            * Typography
            * Colours
            * Spacing
            * Flexbox
            * CSS Grid
            * Borders and shadows
            * Pseudo-classes
            * Form styling
            * Responsive images
            * Media queries
            * Responsive navigation

    ---

    External CSS:

        An external stylesheet called `style.css` was created inside the `css` folder.

        It is linked to all five pages:
        <link rel="stylesheet" href="css/style.css">

        Using one stylesheet allows the same design to be used across the whole website and makes the CSS easier to manage.

        The stylesheet contains styling for the body, headings, header, navigation, sections, images, links, forms, buttons, maps and footer.

    Design and Colour Scheme:

        I used a blue and green colour scheme for the CodeBridge website.

        The main colours include:

        - Dark blue for the header, navigation and footer.
        - Blue for headings and links.
        - Green for some headings and hover effects.
        - White for the main content sections.
        - Light grey/blue for the background.
        - Yellow for focus outlines.

        The colours were chosen to give the website a clean and educational appearance.

    Typography:

        The website uses "Segoe UI" and Arial as the main fonts.

        The headings use "Poppins", with "Segoe UI" and `sans-serif` as fallback fonts.

        The headings were also given different sizes to create a clear hierarchy between the main headings and smaller headings.

        Paragraph spacing and line height were also adjusted to make the content easier to read.


    CSS Reset

        A CSS reset was added at the beginning of the stylesheet.
        * {
            margin: 0;
            padding: 0;
            box-sizing: border-box;
        }

        This removes the default margin and padding applied by browsers and makes the website layout more consistent.

        The `box-sizing: border-box` property also makes it easier to control the size of elements.


    Header and Navigation:

        The header was styled with a dark blue background and white text.

        The navigation was created using Flexbox so that the navigation links can be arranged neatly across the page.

        The navigation includes:

        - Home
        - About Us
        - Lessons
        - Enquiry
        - Contact

        Icons were also added next to the navigation text.

        The navigation links have padding, rounded corners and hover effects.

    ---

    Pseudo-Classes:

        I used CSS pseudo-classes to make the website more interactive.

        :hover
        The :hover pseudo-class changes the appearance of links and buttons when the user moves the mouse over them.

        :focus
        The :focus pseudo-class gives a visible outline when an interactive element is selected.
        This is also useful for users who use a keyboard to navigate the website.

        :active
        The :active pseudo-class changes the appearance of a link or button while it is being clicked.

        These effects were added to the navigation links, normal links and buttons.

    Page Layout:

        The main content was given a maximum width so that very large screens do not make the text too wide.
        The sections were styled as content cards with:
        - White backgrounds
        - Borders
        - Rounded corners
        - Padding
        - Margins
        - Box shadows
        This creates separation between different sections of information.

    CSS Grid:

        CSS Grid was used for sections that contain multiple articles.

        For example, the programming topics on the Home page can be displayed in a two-column layout on larger screens.
        The following CSS was used:

        section:has(article) {
            display: grid;
            grid-template-columns: repeat(2, 1fr);
            gap: 20px;
        }
        The heading is also made to span across the full width of the grid.
        On smaller screens, the grid changes to one column.

    Images:

        Images throughout the website were made responsive using:
        img {
            max-width: 100%;
            height: auto;
        }

        This prevents images from becoming wider than their containers.
        The images also have rounded corners and are displayed as block elements.
        This allows the images to adjust when the screen size changes.

    Forms:

        The Enquiry page contains a form for learners who want more information about the programming lessons.
        The form includes:

        - Full name
        - Email address
        - Phone number
        - Age group
        - Programming course
        - Preferred location
        - Enquiry message
        - Updates checkbox
        - Submit button
        - Clear button

        CSS was used to make the form controls the same width and to give them consistent spacing, borders and padding.
        Focus styling was also added to the form controls.

    ---

    Buttons:

        The Submit and Clear Form buttons were styled using CSS.
        The buttons have:

        - Background colours
        - White text
        - Padding
        - Rounded corners
        - A pointer cursor
        - Hover effects
        - Focus effects
        - Active effects

        The reset button also has a different colour so that it can be distinguished from the submit button.
    Contact Page:

        The Contact page contains the CodeBridge contact information and learning centre locations.

        The page includes two embedded maps.

        The maps were also made responsive using CSS so that they can fit smaller screens.

        The iframe width changes to fit the available space while the height is reduced on smaller devices.

    Responsive Design:

        Responsive design was added so that the website can be viewed on different screen sizes.

        The website was designed for:
        - Desktop
        - Tablet
        - Mobile

        Media queries were used to change the layout when the screen becomes smaller.

        Tablet – 768px:

            The first responsive breakpoint is:
            @media (max-width: 768px)
            At this size:

            - The main heading becomes smaller.
            - Main content padding is reduced.
            - The article grid changes from two columns to one column.
            - The map height is reduced.

        Mobile – 480px:

            The second breakpoint is:
            @media (max-width: 480px)
            At this size:

            - Header padding is reduced.
            - The main heading becomes smaller.
            - Navigation links are stacked vertically.
            - Navigation links use the full available width.
            - Section padding is reduced.
            - Form padding is reduced.
            - Buttons become full width.
            - Maps become shorter.
            - Footer text becomes smaller.

        This allows the website to remain usable on smaller screens.

    Accessibility:

        Basic accessibility was considered during the development of Part 2.
        The website includes:

            - Alternative text for informative images.
            - Empty `alt` attributes for decorative navigation icons.
            - Semantic HTML elements such as `header`, `nav`, `main`, -section`, `article` and `footer`.
            - Labels for form controls.
            - Visible focus outlines for links, form controls and buttons.
            - Responsive layouts for different screen sizes.
            - Readable text and spacing.

    The yellow focus outline makes it easier to see which interactive element is currently selected.
